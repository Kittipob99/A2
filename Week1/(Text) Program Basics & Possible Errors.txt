Basic Demo:
ในอาทิตย์แรกตัวโปรแกรมยังไม่สามารถคัดแยกขยะแบบอัตโนมัติได้แบบสมบูรณ์และจะจัดการขยะตามวัตถุดิบหลัก 
การตรวจจับขยะของโปรแกรมจะทำการอ่านจาก Text File (.txt) ซึ่งในค่าพื้นฐานของโปรแกรมจะอ่านไฟล์ที่มีชื่อว่า "trash.txt" โดยจะใช้ Class และฟังก์ชั่นในการคำนวณอีกทีหนึ่ง ดังนั้นการใส่ข้อมูลใน Text File จะต้องเรียงลำดับดังนี้
 
"**ชื่อขยะ**, **วัตถุดิบ (ในตัวโปรแกรมจะมีแค่ โลหะ, พลาสติก, กระดาษ)** และ **เบอร์ของถังขยะ (0, พลาสติก | 1, กระดาษ | 2, โลหะ โดยจะถูก +1 ในโปรแกรมเพื่อให้คนอ่านได้สะดวก)**"

Possible Errors:

1.ใส่เบอร์ถังขยะใน Text File เกิน 2 หรือน้อยกว่า 0
2.Text File ไม่สามารถอ่านได้ (ต้องอยู่ในโฟลเดอร์เดียวกับตัวโปรแกรม หรือ อาจตั้งชื่อไม่ตรงกับที่เขียนไว้ในตัวโปรแกรม)
